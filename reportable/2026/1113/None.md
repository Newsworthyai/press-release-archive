# UGI System Upgrade Project Set to Begin Next Week in Stroud Township

FOR IMMEDIATE RELEASE - NOVEMBER 13, 2026

UGI Utilities is scheduled to begin a system upgrade project Monday, November 16, 2026, in Stroud Township, Monroe County. The natural gas main replacement is part of UGI’s commitment to provide safe and reliable service and is expected to be completed by early December.
